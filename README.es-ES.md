

# Script de Utilidad
## Descripción
Este script está diseñado para probar la instalación de pytorch + GPU en cualquier nueva máquina.
Verificará si hay una GPU disponible y ejecutará un entrenamiento de 10 épocas en el conjunto de datos CIFAR10.
## Instalación
ejecute el comando `pip install test-pytorch-gpu`
## Uso
ejecute el comando `run_cifar`
